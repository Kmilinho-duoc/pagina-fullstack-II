#  Pastelería 1000 Sabores

Proyecto académico desarrollado para la creación de una página web de una pastelería, enfocada en presentar productos de manera atractiva y permitir la interacción del usuario con el catálogo.

## Descripción del proyecto

El proyecto consiste en el desarrollo de un sitio web para una pastelería, diseñado para mostrar su catálogo de productos y proporcionar una experiencia de navegación sencilla e intuitiva.

La aplicación fue desarrollada utilizando tecnologías web fundamentales como **HTML, CSS y JavaScript**, incorporando funcionalidades dinámicas mediante JavaScript.

Además, el proyecto contará con pruebas automatizadas utilizando **Jasmine** y **Karma**, con el objetivo de verificar el correcto funcionamiento de las funcionalidades implementadas.

## Tecnologías utilizadas

* **HTML** — Estructura y contenido de las páginas.
* **CSS** — Diseño, estilos y presentación visual.
* **JavaScript** — Funcionalidades e interacción dinámica.
* **Jasmine** — Framework utilizado para realizar pruebas unitarias.
* **Karma** — Herramienta utilizada para ejecutar las pruebas automatizadas.
* **Git / GitHub** — Control de versiones y almacenamiento del proyecto.

## Funcionalidades

Entre las principales funcionalidades desarrolladas se encuentran:

* Visualización del catálogo de productos.
* Interacción con los productos.
* Gestión del carrito de compras.
* Persistencia de información del carrito mediante `localStorage`.
* Diseño adaptable a diferentes tamaños de pantalla.
* Pruebas unitarias de las funcionalidades mediante Jasmine.
* Ejecución de pruebas automatizadas utilizando Karma.

##  Contexto académico

Este proyecto fue desarrollado con fines **académicos**, como parte del aprendizaje de desarrollo web y pruebas de software.

El objetivo principal fue aplicar conocimientos de **HTML, CSS, JavaScript, testing y control de versiones**, desarrollando una aplicación web funcional y verificando su comportamiento mediante pruebas automatizadas.

#¿Cómo Explorar La Página Web?
* Opción 1 : Descargar el archivo ZIP en tu escritorio >> PaginaWebPasteleria >> pages >> index.html
* Opcion 2: Clonar el repositorio en Visual Studio Code >> PaginaWebPasteleria >> (puedes explorar el código completo a tráves de las carpetas) >> index.html >> run >> open with Chrome ( o con el motor de búsqueda de tu preferencia), en nuestro caso nosotros lo abrimos con Apache.
  
#¿Problemas Para Visualizar La Página Web?
* Solución 1 : Verificar que las carpetas se encuentren ordenadadas
* Solución 2: Instala Node.js y ejecuta en la terminal de Visual Studio Code los script npm install y luego npm run dv
